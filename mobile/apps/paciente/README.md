# LarsanaCare Paciente

App mobile Expo para usuários com papel **paciente** (família/responsável).

- **Role:** `paciente`
- **Status:** ativo
- **Login dev:** `cliente@larsanacare.com.br` / `LarsanaCare2026!`

## Rodar

```bash
cd mobile/apps/paciente
npm install
npm start

# ou na raiz:
npm run dev:mobile -- paciente
npm run dev:mobile:paciente
```

Configure `.env` com `EXPO_PUBLIC_SUPABASE_URL` e `EXPO_PUBLIC_SUPABASE_ANON_KEY`.
