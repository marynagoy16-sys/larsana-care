# LarsanaCare Financeiro

App mobile Expo para usuários com papel **financeiro** ou **admin**.

- **Roles:** `financeiro`, `admin`
- **Status:** ativo
- **Login dev:** `financeiro@larsanacare.com.br` / `LarsanaCare2026!`

## Rodar

```bash
cd mobile/apps/financeiro
npm install
npm start

# ou na raiz:
npm run dev:mobile -- financeiro
npm run dev:mobile:financeiro
```

Configure `.env` com `EXPO_PUBLIC_SUPABASE_URL` e `EXPO_PUBLIC_SUPABASE_ANON_KEY` (copie de `mobile/apps/profissional/.env` se necessário).
